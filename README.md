# NEXUS | V9.0 The Architect

NEXUS is a high-performance, futuristic dashboard system inspired by advanced OS simulations. It features a stunning 3D starfield background, glassmorphism UI, a robust game center with 10-level progression, and advanced system commands.

## Key Features
- **3D Starfield Warp Background**: Immersive Three.js particles reacting to mouse movement.
- **Advanced UI/UX**: Glassmorphism, smooth animations, and neon aesthetics.
- **Arcade Engine V2**: 10-level progression for games like Snake, Pong, Breakout, and Tetris.
- **100+ Terminal Commands**: Comprehensive system control through a command-line interface.
- **Quick Access Dock**: Instant links to developer-favorite platforms like GitHub, Google, and LeetCode.
- **Voice Control**: Execute commands using speech recognition.
- **Built-in Utilities**: Audio visualizer, metrics tracking, timer, and persistent notes.

## Installation
Just open `jsns.html` in any modern web browser.

## Technologies
- HTML5 / CSS3 (Vanilla)
- JavaScript (Vanilla)
- Three.js (3D Rendering)
- Web Speech API
- LocalStorage (Persistence)
